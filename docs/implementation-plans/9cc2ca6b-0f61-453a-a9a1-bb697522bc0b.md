# Implementation plan: Premium redesign of ThePackage

## Goal
Remake the entire site (index.html, Communication.html, video.html) with a premium, restrained visual system using Inter (Thin 100 for display, Regular 400 / Medium 500 for UI). Avoid common AI‑slop tells: gradients, glow box‑shadows, glassmorphism bubbles, generic centered card stacks, neon accents, decorative blobs. Keep the existing brand "ThePackage" (video editing / motion / thumbnails) and the existing assets (Logo.png, video.mov, timine_1.2.3.jpg, back2.png, local fonts).

## Background / repo context
- `index.html` currently has a fixed translucent glass header, hero with rotating JPG background, three rounded "bubble" cards (Pros, Pricing, Contact), inline JS for hero rotation and smooth scrolling, broken `</main>` (no opening tag).
- `Communication.html` is a near‑clone of index, broken semantics, references `Home.html` from video.html (file does not exist — must point to `index.html`).
- `video.html` is a fullscreen video intro with embedded `<style>` and an `Explore Now` link pointing to `Home.html` (should be `index.html`).
- `home.css` uses Turnpike/LuckiestGuy as display fonts, neon CTAs (`#86ffff`, `#4024c0`, `#66a396`), heavy translucent glass, drop shadows, and gradient‑style dark backgrounds. The task is to remove these tells and rebuild with a calm editorial layout.

## Visual system (no slop)
- Type: Inter from Google Fonts, weights 100/300/400/500 only. Display headings use weight 100 with tight tracking and large size; body uses 400; UI uses 500. No custom display font gimmicks.
- Palette: off‑white paper `#F4F2EE` for the page, near‑black ink `#111111` for type, a single accent `#1A1A1A` for borders/lines, muted gray `#8A8784` for secondary text. No gradients, no shadows. Hairline 1px borders for separation.
- Layout: 12‑column grid, generous whitespace, large left‑aligned display headings, asymmetrical content blocks instead of centered stack‑of‑cards. Hero is editorial type over a single image, no auto‑carousel.
- Buttons: rectangular, 1px border, no radius (or 2px max), no shadow, no gradient. Hover inverts fg/bg.
- Hero image: keep `timine_1.2.3.jpg` as a single large full‑bleed image with a subtle duotone via CSS `filter: grayscale(1) contrast(1.05)` and an inset darken for legibility, not a gradient overlay blob.

## Files and areas
- `home.css` — full rewrite: CSS variables, Inter import, new layout, new components (`.btn`, `.btn--solid`, `.nav`, `.hero`, `.section`, `.rule`, `.grid`, `.card‑line`, `.footer`, `.contact‑row`, responsive breakpoints).
- `index.html` — semantic structure (`<header><nav>`, `<main>` properly opened, `<section>` per topic, `<footer>`), copy rewritten to sound professional and specific (what ThePackage actually does: video editing, motion graphics, thumbnails), single hero, scannable sections.
- `Communication.html` — same shell as index, focused on contact channels (Discord, WhatsApp, Email) with the new visual system.
- `video.html` — keep fullscreen video intro but align with new palette/typography, fix the broken link target to `index.html`, keep skip button, but restyle to match.
- No asset deletions; existing `Logo.png` is reused (kept at small size in nav).

## Implementation steps
1. Rewrite `home.css` end‑to‑end with the new design tokens, typography scale, layout primitives, components, and responsive rules. No gradient/box‑shadow/glow utilities.
2. Rewrite `index.html` with proper semantic markup, the new nav (logo wordmark + 3 links), editorial hero (display headline + sub + 2 buttons), an "About" section, a "Services" list (Editing, Motion, Thumbnails) presented as a bordered table‑like list, a "Pricing" section, a "Contact" section with channel rows, and a minimal footer.
3. Rewrite `Communication.html` with the same header/footer shell and a focused 3‑channel layout (Discord / WhatsApp / Email) using `.contact‑row` components.
4. Refine `video.html`: keep fullscreen video background, restyle the Explore link and Skip button with the new system, fix the href to `index.html`, ensure it works before/after video end.
5. Run `repo.html_validate` on each HTML file, `repo.css_selectors` and `repo.css_audit` on `home.css`, and `repo.preview_page` for smoke checks.

## Edge cases and interactions
- Mobile (≤640px): collapse nav into a single wordmark, stack sections, keep generous line height.
- The hero image is decorative — provide a meaningful `alt` and a CSS `background-color` fallback so it never flashes black.
- All external links open in a new tab with `rel="noopener noreferrer"`.
- `prefers-reduced-motion` respected (no auto‑rotation, no transitions on transform).

## Verification
- `repo.html_validate` returns no unclosed tags on the three HTML files.
- `repo.css_audit` shows no hardcoded colors outside the declared token set and no `box-shadow`/`linear-gradient`/etc.
- `repo.css_selectors` reports no unintended duplicates.
- `repo.preview_page` confirms referenced local assets (Logo.png, video.mov, timine_1.2.3.jpg) resolve.
- Visual smoke check via `repo.preview_page` for index.

## Risks and open questions
- The brand is "ThePackage" but the existing index.html says "Augmented". I will standardize on **ThePackage** since the repo, README, and video.html all use it; this is the only safe interpretation.
- Existing local TTF fonts are intentionally not used; Inter replaces them to satisfy the brief. Files stay on disk so we don't break references if someone reverts.
- `video.html` previously linked to a non‑existent `Home.html`; fixed to `index.html`.
